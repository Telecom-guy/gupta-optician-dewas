# Gupta Optician — Dewas

A simple, mobile-first website for Gupta Optician, an optical shop in Dewas, Madhya Pradesh, India. It covers two stores: the original shop in Alankar Market on MG Road, and the new shop on AB Road, near Abhilasha Hotel.

This is a static site: open `index.html` in a browser, or serve the folder with any static file server. There is no build step.

## Features

- English and Hindi, with a हिंदी / English switch in the header. The choice is remembered in the browser. If the browser language is Hindi, the site starts in Hindi.
- Call buttons and Google Maps directions for both stores.
- Service descriptions limited to what public listings and reviews actually support.
- Verbatim Google review quotes.
- A language toggle that works without reloading the page.

## Languages

Use the **हिंदी / English** control in the header (it stays visible on a phone). The page language, title, and description update at once.

## Local files

- `index.html`, `styles.css`, `script.js`, `favicon.svg` — the site
- `images/` — stock photographs and static maps
- `NOTES.md` — every factual claim and its source
- `screenshots/` — preview captures

## Accuracy

Please read `NOTES.md` before adding new claims. Do not publish email addresses, extra phone numbers, WhatsApp links, ratings, brand names, or social profiles unless they have been confirmed.

# गुप्ता ऑप्टिशियन — देवास

यह देवास, मध्य प्रदेश की ऑप्टिकल दुकान गुप्ता ऑप्टिशियन की एक सरल, मोबाइल-अनुकूल वेबसाइट है। इसमें दो दुकानें हैं: एम.जी. रोड, अलंकार मार्केट की पुरानी दुकान, और ए.बी. रोड पर, अभिलाषा होटल के पास की नई दुकान।

यह एक स्थिर (स्टैटिक) साइट है। `index.html` को ब्राउज़र में खोलें, या इस फ़ोल्डर को किसी भी स्टैटिक सर्वर से चलाएँ। कोई बिल्ड स्टेप नहीं है।

## विशेषताएँ

- अंग्रेज़ी और हिंदी, हेडर में हिंदी / English बटन के साथ। आपकी पसंद ब्राउज़र में याद रहती है। यदि ब्राउज़र की भाषा हिंदी है, तो साइट हिंदी में खुलती है।
- दोनों दुकानों के लिए कॉल बटन और गूगल मैप का रास्ता।
- सेवाओं का वर्णन केवल उन्हीं बातों तक सीमित है, जिनका समर्थन सार्वजनिक लिस्टिंग और समीक्षाएँ करती हैं।
- गूगल समीक्षाओं के अंश जैसे के तैसे।
- भाषा बदलने पर पेज दोबारा लोड नहीं होता।

## भाषा

हेडर में **हिंदी / English** बटन का उपयोग करें (यह मोबाइल पर भी दिखता रहता है)। पेज की भाषा, शीर्षक और विवरण तुरंत बदल जाते हैं।

## फ़ाइलें

- `index.html`, `styles.css`, `script.js`, `favicon.svg` — साइट
- `images/` — स्टॉक तस्वीरें और स्थिर नक्शे
- `NOTES.md` — प्रत्येक तथ्य और उसका स्रोत
- `screenshots/` — पूर्वावलोकन चित्र

## सटीकता

नई जानकारी जोड़ने से पहले `NOTES.md` पढ़ें। ईमेल, अतिरिक्त फ़ोन नंबर, व्हाट्सऐप लिंक, रेटिंग, ब्रांड नाम या सोशल प्रोफ़ाइल तभी प्रकाशित करें जब उनकी पुष्टि हो चुकी हो।
